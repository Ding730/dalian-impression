      关于本项目

      《大连印记：从过去到未来的数字漫游》以「历史长廊 / 今日大连 / 未来规划」三大篇章， 用交互式时间轴、老地图联动、数据可视化大屏与规划互动地图，讲述一座滨海城市从 1899 年建市到面向未来的故事。

      技术实现

      • 原生 HTML5 + CSS3：Grid 布局、CSS 变量、关键帧动画与响应式适配
      • GSAP + ScrollTrigger：滚动视差、首屏分层入场与时间轴动效
      • Apache ECharts 5：多图表数据可视化（折线 / 柱状 / 玫瑰 / 雷达 / 面积）
      • Canvas 粒子系统 + 手绘 SVG 老地图与规划示意图（离线可用）
      • localStorage：留言板数据本地持久化

      数据与素材说明

      页面中的老地图、区域规划图与地铁线位均为本作品手绘 SVG 示意，非精确测绘、非官方公示线位； 统计数据依据公开报道与政府公开文件整理并做简化，标注为演示数据，仅用于作品展示。
